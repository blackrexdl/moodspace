## 💡 Overview

MoodSpace is an AI-powered mental wellness and social platform designed to improve digital well-being. It uses Artificial Intelligence (AI), Machine Learning (ML), and Natural Language Processing (NLP) to analyze emotions and filter content based on its emotional impact.

The platform focuses on creating a safer and more personalized social media experience by reducing exposure to emotionally harmful content.

---

## ✨ Features

### 🧠 AI & Emotion Detection
- Text-based emotion detection using NLP (Naive Bayes + TF-IDF)
- Detects emotions like happiness, sadness, stress, and anger
- AI/ML-based content filtering system for emotional safety

### 📷 Computer Vision
- Camera-based mood detection using OpenCV
- Image analysis for emotional understanding

### 📊 Wellness Tracking
- Mood tracking dashboard
- Emotional insights and analytics
- Daily journaling system

### 🌿 Health Tools
- 4-7-8 breathing exercise
- Relaxation UI with smooth animations

### 👤 Social Features
- Demo social feed with emotion tags
- User profiles with stats
- Personalized content feed

### 🛡️ Smart Filtering
- Emotion-aware content filtering (AI + ML + NLP)
- Detects anxiety, stress, depression signals
- Focus on safety, not censorship

## 🚀 Getting Started

```bash
git clone https://github.com/blackrexdl/moodspace.git
cd moodspace
```

```bash
python -m venv moodspace-env
source moodspace-env/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
python app.py
```

Open: http://127.0.0.1:5000
